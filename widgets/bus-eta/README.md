# HK Bus ETA | 巴士到站 Widget

**Install:** copy all of [HK-Bus-ETA.js](HK-Bus-ETA.js) into a separate Scriptable script, then select it in the Home Screen widget.

**Current version:** [2.4.0](VERSION.json) · [Release notes](CHANGELOG.md)

Features: KMB / Citybus ETA, three upcoming times, snapshot countdown by default with optional live timer, operator timestamp, separate per-script favourites, selected workdays and adaptive commute-time refresh.

Widget refresh is controlled by iOS; `refreshAfterDate` is not a guaranteed polling frequency.

Documentation: [廣東話](../../docs/README_zh_HK.md) / [English](../../docs/README_en.md) / [Methodology](../../docs/METHODOLOGY.md).

Future changes: update this canonical script and matching legacy `scripts/HK-Bus-ETA.js`, increment VERSION.json and add dated CHANGELOG.
