# Expense Tracker HK — Widget UI v3.22.0

**日期：2026-11-05｜目標：按使用者確認的 Small／Medium／Large 資訊架構重新設計**

## 核心需求與實際實作

| Family | 新版主要內容 | 圖形及展示方式 |
|---|---|---|
| **Small** | **左上今日交易筆數**；大金額＝**今日淨支出**；原「近7日」改為**本月支出**；移除「最多分類」 | 放大本月1日起至今日的**每日 HKD 淨支出柱圖**，下方標示「1日」與「今日」 |
| **Medium** | **左半使用 Small 相同資訊**（今日筆數／今日支出／本月支出／本月每日柱圖） | **右半實心 Pie Chart**，採本月正向消費分類構成；分類名及佔比以原生文字列出 |
| **Large** | 今日／本月雙 KPI，今日及本月交易數、當月每日趨勢、分類比例、付款構成、2–3筆最近交易 | 整月每日淨支出柱圖 + 實心分類 Pie Chart + 付款方法堆疊比例條 |
| **Extra Large（iPad）** | 保留獨立四圖分析版面，包括退款及最近交易，避免非要求範圍的破壞式修改 | 30日、6個月、環形圖及付款比例；數據匯總管道不變 |

**已澄清的重要修改：** Medium 右側是 **Pie（實心圓餅圖）**，不是 Donut。實作使用 Scriptable DrawContext 與 Path，多邊形扇區填色，不以 WebView 呈現。

## 關鍵數據定義

1. **今日交易筆數**＝當天、日期有效、已解析為 HKD 金額的交易記錄筆數；退款有效但 0 元或未換算交易不會在 HKD Widget KPI 當作已解析。這與本月全部交易筆數不同。
2. **今日淨支出**＝當天有效已換算 HKD 正向消費之和，減當天退款絕對值。
3. **本月淨支出**＝當月有效已換算 HKD 消費減退款；從自然月1日起至今日。
4. **本月每日柱圖**＝按月份日期 1、2、…、今日逐日顯示 signed net HKD。金額為零的日期不虛構支出；負值按既有退款圖色顯示。由於係逐日金額而唔係累積金額，不會將沒有消費的日期畫成滿柱。
5. **分類 Pie Chart**＝本月所有**正向消費金額（退款前）**作為100%的分母；最多採 Top 2+「其他」（Medium），令每個顯示圖例與每個顏色扇區一一對應。
6. **Large 付款構成圖**同樣採正向消費，與今日／本月淨額的定義不同；標題明確寫「退款前」。
7. **外幣**：未換算 HKD 的紀錄保留於原檔並等待核對，不會假裝 HKD0 進入金額圖；本次不更改任何匯率。
8. **資料表**：原 `ExpenseTrackerHK/transactions.json`、付款名稱、Remark、手動編輯及左滑刪除、Tap Card、Shortcuts、Numbers 六欄欄位完全不變。

## 視覺層級

### Small
```text
今日支出                  4筆
HK$200.30             ← 今天淨支出
本月支出            HK$200.30
[本月1日至今日每日柱圖，盡用可讀空間]
1日                        今日
```
「最多分類」整行移除；不再把七日柱圖標成「本月」。本月與今日即使剛好同額，仍因代表不同時間範圍而都要顯示。

### Medium
```text
┌ 左：與Small一致 ┐  ┌ 右：本月分類 ┐
今日支出 4筆          本月分類
HK$200.30             [實心Pie Chart]
本月 HK$200.30        訂閱50%
[本月每日柱圖]        食飯28%
1日—今日              其他22%
```
兩欄分別擁有獨立內容；唔再一邊列數字、另一邊放沒有實際分類說明的散柱圖。

### Large
```text
記帳總覽 11月             今日4筆 · 本月4筆
今日支出 HK$200.30       本月支出 HK$200.30
本月每日淨支出 [較大的全寬日期柱圖]
分類 · 退款前 [實心Pie + 彩色圖例] | 付款 · 退款前 [比例條及金額]
最近交易 [最多3筆，窄屏2筆]
```
重點資訊由上而下，一眼看到「今日、整月、分類、付款、明細」，無虛構預算、收入或結餘。

## 自動化品質控制

- 編譯：JavaScript `node --check`。
- 資料：今日 HKD、今日筆數、自然月月份合計、退款、空資料、pending FX、特殊 paymentType `__proto__` 等案例。
- 圖形：Small 1圖、Medium 2圖（本月柱圖＋真正**實心 Pie**）、Large 3圖（柱圖＋Pie＋付款比例），iPad Extra Large保留4圖。
- **Pie 實心驗證：** 顏色扇區確實有 Path 繪圖，只有外圍圓形底層，無 Donut 的內圈挖洞。
- 尺寸：393pt及320pt iPhone Small／Medium／Large；iPad 768pt／1024pt Extra Large。
- 相容性：主 Script 與 `scripts/HK-Expense-Tracker.js` 副本位元組一致；資料格式沒有遷移。
- **限制：** GitHub CI 模擬 Scriptable Widget 樹與估算高度，不能代替真機截圖。須在 Scriptable 預覽 Small／Medium／Large，實機檢查文字裁切及圓餅比例。
